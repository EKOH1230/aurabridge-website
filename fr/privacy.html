Ce site n’utilise ni cookies ni traceurs

Nous n’exploitons pas de comptes utilisateurs sur ce site.

Formulaire de devis

Le formulaire « Demander un devis » n’envoie pas vos données vers un serveur de ce site et ne les enregistre pas dans une base ici. Après saisie des champs obligatoires, votre messagerie s’ouvre avec un message prérempli. Le message n’est envoyé que si vous l’expédiez vous-même.

Si vous envoyez cet e-mail, nous recevons :

  • votre nom ;
  • votre adresse e-mail ;
  • le nom de votre société, si vous l’avez indiqué ;
  • le produit choisi ;
  • votre message.

L’e-mail est envoyé à ohashi@brightbridgegroup.com, avec copie à ikkei@brightbridgegroup.com.

Finalité : répondre à votre demande de devis de gros ou d’échantillon, et assurer le suivi de cette demande.

Base juridique : l’exécution de mesures précontractuelles prises à votre demande (article 6, paragraphe 1, point b, du RGPD).
